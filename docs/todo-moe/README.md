# Todo Moe（暂定名）开发文档

把 Mindwtr 二次开发为适合自己日用的 Android 待办：快速记录、文件夹与多清单、完成动画、家族品牌、模糊或液态玻璃，并保留数据与同步能力。

**当前进度：方案文档已建立；应用开发尚未开始。** 本目录最初为空。本次交付依据「推荐待办应用」的 3 轮聊天，整理开发方案和分版本计划；没有现成源码、APK、构建、安装或发布记录。名称、包名、远端仓库和版本划分均按下文标注状态。

## 从这里开始

1. 阅读 [需求与范围](docs/01-需求与范围.md)，确认原始需求、默认方案和待定输入。
2. 阅读 [交互与视觉设计](docs/02-交互与视觉设计.md) 与 [架构与工程方案](docs/03-架构与工程方案.md)，查看要做什么、如何接入上游。
3. 打开 [版本索引](docs/versions/README.md)，按 v0.1.0 → v0.2.0 → v0.3.0 → v0.4.0 → v1.0.0 推进。
4. 每次开发更新 [开发台账](docs/06-开发台账.md) 和对应版本文档；每个测试包、补丁版、预发布版均复制 [版本记录模板](docs/templates/版本记录模板.md) 单独记录。
5. 构建与发布前对照 [测试与发布维护](docs/05-测试与发布维护.md)，填实际执行结果与证据。

## 使用约定

“已实现”需要代码；“构建通过”需要构建日志；“已安装”需要设备记录；“验收通过”需要相应行为证据。“计划中”和“未执行”保留到证据齐全再更改。每次变化填写日期、版本、提交、测试和未验证事项，文档不包含私钥、口令或真实同步凭据。
