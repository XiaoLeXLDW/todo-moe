# Todo Moe 需求来源摘要

本项目最初来自 2026-09-11 起的产品讨论。原始对话没有继续保存在公开源码树中；本摘要只记录已经进入项目决策的目标，不包含会话标识、搜索引用或助手原文。

## 已确认方向

- 基于 Mindwtr 长期维护一个独立品牌的 Android fork。
- 重点改善快速记录、多清单组织、完成反馈、主题和玻璃界面。
- 保留本地数据、备份、可选同步和上游兼容能力。
- 使用 Todo Moe 独立包名、签名、图标、帮助、隐私与发布入口。
- checklist 使用现有 `checklist[].isCompleted` 与 `taskMode`，在任务列表中直接展开执行。
- 自动化、APK 核验、真机观察和公开发布分别提供证据。

## 使用方式

本摘要用于解释产品方向，不是当前任务列表、版本状态或发布授权。当前工作从[维护入口](../README.md)开始；历史版本事实从[版本索引](versions/README.md)读取。
