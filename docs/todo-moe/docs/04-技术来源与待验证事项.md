### 3.2 更正“SQLite 都在 packages/core”

共享核心含 `SqliteClient` 接口、`SqliteAdapter` 和 schema；移动端 `apps/mobile/lib/storage-adapter.ts` 创建原生 SQLite 客户端、打开数据库并接入核心适配器。上游 ADR 0024（2026-07-12，Accepted）记录了从 `expo-sqlite` 改为 `op-sqlite` 的决定。Expo Go/网页路径不能用作原生数据库行为的验收依据。来源：[共享 SQLite 适配器](https://github.com/dongdongbh/Mindwtr/blob/c035ae041ba1b8a4e4fae3bf16036a4a8dd2c160/packages/core/src/sqlite-adapter.ts)、[共享 schema](https://github.com/dongdongbh/Mindwtr/blob/c035ae041ba1b8a4e4fae3bf16036a4a8dd2c160/packages/core/src/sqlite-schema.ts)、[移动端存储 ADR](https://github.com/dongdongbh/Mindwtr/blob/c035ae041ba1b8a4e4fae3bf16036a4a8dd2c160/docs/adr/0024-mobile-native-sqlite-engine.md)。

**工程判断：**“主要修改 `apps/mobile`”不能理解为这个目录里的所有代码都是 UI。应把移动端持久化、同步适配、重复任务、完成操作及错误恢复一起列为受保护路径。动画不改变原有业务提交时机；保留正在退场的视觉行，不额外维护一套真实任务状态。

### 4.2 独立 Dev 身份和 Debug 构建不同

上游 `app.json` 的基础名称、Android 包名和 URI scheme 分别为 `Mindwtr`、`tech.dongdongbh.mindwtr`、`mindwtr`；`app.config.ts` 在 development variant 下追加名称后缀 ` Dev` 和包名后缀 `.dev`。因此源码具备生成 `Mindwtr Dev` / `tech.dongdongbh.mindwtr.dev` 的配置逻辑。来源：[app.json](https://github.com/dongdongbh/Mindwtr/blob/c035ae041ba1b8a4e4fae3bf16036a4a8dd2c160/apps/mobile/app.json)、[variant 配置](https://github.com/dongdongbh/Mindwtr/blob/c035ae041ba1b8a4e4fae3bf16036a4a8dd2c160/apps/mobile/app.config.ts)。

上游 `android-debug-build.yml` 调用 `android_build_debug.sh`；这两份文件本次未见设置 `APP_VARIANT=development`。不能因为产物名字含 `debug.apk`，就断言已经使用 `.dev` 包名。独立身份须检查最终 manifest 和安装结果。来源：[Debug 工作流](https://github.com/dongdongbh/Mindwtr/blob/c035ae041ba1b8a4e4fae3bf16036a4a8dd2c160/.github/workflows/android-debug-build.yml)、[Debug 构建脚本](https://github.com/dongdongbh/Mindwtr/blob/c035ae041ba1b8a4e4fae3bf16036a4a8dd2c160/apps/mobile/scripts/android_build_debug.sh)。

**工程判断：**Dev 与正式版要分别验证本地数据空间、导入测试数据和远端同步目标。不同包名不为同一个 WebDAV 目录或自托管服务自动创建隔离数据集。

| 真实背景 | 滚动彩色 RN 列表时，底栏下方的颜色、模糊与折射连续变化；关闭背景内容后结果随之变化 |
| 手势 | 导航点击、可能采用的拖动交互和列表滚动不互相吞事件，返回行为明确 |
| 布局 | 键盘、安全区、横竖屏以及目标设备可能涉及的折叠状态下不遮挡正文和输入区域 |
| 性能 | 同一场景玻璃开启/关闭对比，保留设备、系统、构建、任务规模、帧时间/掉帧和资源开销记录 |
| 降级 | 关闭玻璃后导航仍完整可用；减少动态效果时不影响完成和保存业务 |

用户已经在其他 App 使用成功的底栏版本、项目路径及准确提交仍未取得。优先复用那份实现的方向保持不变；本文查询到的最新 SukiSU 不能冒充用户已使用的版本。目标 Android/RN/Compose 跨渲染层采样、最低系统要求与具体设备性能均待实机验证。

## 7. Expo 官方适用边界

| 能力 | 本次官方文档结论 | 对本项目的限制 |
|---|---|---|

## 8. GitHub Actions 与 Obtainium

| 事项 | 官方文档本次说明 | 自动化验收要求 |
|---|---|---|
