# Todo Moe 需求与范围

产品目标来源见[需求来源摘要](requirements-origin.md)。本文件只保留仍然有效的边界；版本状态以[当前维护入口](../README.md)和[版本索引](versions/README.md)为准。

## 当前目标

- 提供适合 Android 日用的本地优先待办、多个清单、分组和文件夹体验。
- 保留 Mindwtr 的任务、Project、Section、Area、checklist、备份与同步数据模型。
- 强化快速记录、直接执行 checklist、完成与撤销反馈、主题、触感和玻璃界面。
- 使用 Todo Moe 独立包身份、品牌、帮助、隐私入口和受控发布流程。
- 保留上游版权、Git 历史、AGPL 与第三方许可，并能持续合并上游变化。

## 身份与交付

| 项目 | 当前值 |
|---|---|
| 正式应用 | Todo Moe / `io.github.xiaolexldw.todomoe` / `todomoe` |
| 开发应用 | Todo Moe Dev / `io.github.xiaolexldw.todomoe.dev` / `todomoe-dev` |
| 当前交付平台 | Android |
| 数据关系 | Stable 与 Dev 独立；迁移使用受支持的导出与恢复 |
| 网络关系 | 本地使用无需账号；同步与外部服务由用户配置 |

## 非目标

- 不创建第二套任务或 checklist schema。
- 不把上游其他平台目录宣传为已发布的 Todo Moe 产品。
- 不用视觉动画替代业务写入，也不把构建成功写成真机验收。
- 不删除兼容键、同步字段、许可或上游历史来追求表面整洁。
- 不从早期计划文档继续执行已经被后续版本取代的步骤。
