## 目标与范围

交付完整的“快速记录 → 文件夹/清单整理 → 完成与撤销”日常路径。动画增强操作反馈，持久化与同步继续通过原有业务接口执行。

| 纳入范围 | 本版不做 |
|---|---|
| 简化首页导航与独立快速添加入口 | 不删除上游 GTD、标签、提醒、同步等底层能力 |
| 文件夹/清单/分组的直观显示与可访问操作 | 不凭显示名另建同步层级，不改任务 schema |
| 完成、添加、按压、滑动、展开收起动画及轻触感 | 不以动画计时器驱动保存，不重写原有重复任务逻辑 |
| 真实清单完成时的小范围庆祝及事件去重 | 不每勾一条撒彩带，不以筛选后列表为空触发庆祝 |
| 已验证玻璃、主题预设、关闭/减弱动画与降级 | 不加 AI 聊天、打卡惩罚、积分商城或复杂养成 |

“今天 / 清单 / 收件箱”、Area→文件夹、Project→清单、Section→分组、三种视觉预设和动画数值均来自历史助手建议，作为候选方案。它们没有变成用户已确认的信息架构；应在原型/首个可运行页面上核对命名和手感，并在执行记录写下决定。

## 具体功能设计

### 快速记录与多清单

首页能触达今天、清单、收件箱等日常视图；“＋”是操作按钮而非伪导航页面。新增面板明确显示保存位置，支持键盘提交及连续添加，避免空文本、重复点击和网络状态导致重复任务。具体入口排列通过首个可运行页面决定。

文件夹/清单/分组优先映射上游实体，名称改变不改字段。创建、重命名、展开收起、移动和排序只接入原已支持且本版需要的能力；若 Area/Project 生命周期语义与“文件夹/清单”冲突，先在交互中解释或调整标签，不强行伪装成另一种数据模型。已有高级数据应仍可找到。

### 动画动作表

下列参数是历史聊天的候选起点，需统一调校；同一动作不要在不同页面各写一套数值。

| 动作 | 候选表现 | 数据与可访问性约束 |
|---|---|---|
| 勾选完成 | Checkbox 缩放约 `1→0.88→1.16→1`、勾线/划线、轻触感、行平滑退出；约 250–350 ms | 立即调用原完成接口；动画临时节点只服务显示，失败恢复真实状态 |
| 添加 | 新行透明度 `0→1`、Y `-8→0`、缩放 `0.98→1`；约 180–220 ms | 保存是否成功以业务结果为准；失败保留输入并可重试，不插入幽灵任务 |
| 按压 | Task、Project、Tag、Button、FAB、Card 候选缩放 `1→0.975→1` | 不改变布局命中区域；取消触摸恢复；不可点组件不伪装成按钮 |
| 滑动 | 动作图标随进度变化、阈值反馈、未达阈值回弹 | 沿用明确的完成/删除等语义；阈值一次触发一次，删除需要可恢复路径 |
| 展开收起 | 箭头旋转、内容高度/透明度过渡，约 100–250 ms | 保持焦点与阅读顺序，快速切换不产生高度错乱或截断 |
| 真实清单完成 | 小范围短庆祝、可选轻触感 | 仅确认本地用户动作导致完整清单从未完成转为完成，不阻塞导航和输入 |

任务完成状态不等待动画结束才写入。用户快速完成多项时可以并行动画；列表重排、切页、卸载组件或返回后台不取消已经提交的业务操作。触感 API 失败不能使任务操作失败。

### 庆祝与异常事件规则

| 事件 | 应有行为 |
|---|---|
| 普通任务完成但清单仍有未完成项 | 只播放该行反馈，不触发整清单庆祝 |
| 本地用户完成真实清单的最后一项 | 基于稳定清单 ID 与完整成员状态确认转换，待业务成功后庆祝一次；不是统计当前可见行 |
| 搜索/筛选/折叠/切页导致列表为空 | 不庆祝；空视图只显示对应空态 |
| 其他设备同步完成、启动加载或后台重放 | 更新真实状态，可用克制的状态过渡；不冒充本地完成，不触发奖励触感与庆祝 |
| 撤销、快速重复点击或重试 | 撤销恢复真实状态并清掉待播奖励；同一完成事务重放不重复庆祝；一次撤销再完成的奖励策略写成明确规则 |
| 重复任务完成后生成下一次任务 | 交给原逻辑创建后继；后继纳入真实清单状态，不把短暂空窗判定为清单清空 |
| 持久化失败/任务被并发删除 | 显示可重试错误，恢复与真实数据一致的行、计数和勾选；不保留成功庆祝 |

建议本版对“撤销后再次完成同一批任务”不重复庆祝；新的真实未完成任务加入后再清空可再次触发。去重以稳定任务/清单与本地事务来源为依据，缓存只属于 UI 辅助状态，不更改同步 schema。若上游无法提供必要因果信息，应缩小庆祝触发条件，宁可少播，不能猜测成功事件。

“今天全部完成”与“Project 全部完成”并非天然等价。本版先实现语义清楚的真实清单庆祝；今天视图若要奖励，需单独定义日期边界、筛选与重复任务规则并补验收，不能直接复用“页面变空”判断。

### 主题与减弱效果

以清晰任务内容为主，玻璃集中在底栏，快速添加/搜索等轻模糊区域按性能验证扩展。浅色、深色、家族色为候选视觉预设；不承诺动态 Material You 是必做功能。

设置候选：玻璃关闭/柔和/液态，动画简洁/标准/活泼，触感关闭/轻。系统减少动画优先于活泼档，简洁模式去掉位移、弹簧和粒子，保留即时明确状态。玻璃不支持时自动使用 v0.2.0 的合格降级，文字仍可读。

| V03-02 多清单 | 创建/打开多个文件夹对应实体与清单、分组，快速展开/收起并切页 | 关系与计数正确，原数据可访问，动画不截断内容、不丢焦点 |
| V03-03 普通完成与保存 | 完成后立刻切页/回后台/重开，再在动画播放中连续完成多项 | 持久化不依赖计时器；结果与上游接口一致，无重复调用和残留视觉行 |
| V03-04 失败恢复 | 注入可控保存失败、并发删除、触感异常 | 明确错误并恢复一致状态，可继续操作；未保存任务无成功庆祝 |
| V03-05 撤销与重复任务 | 动画中撤销、快速完成/撤销/再完成，完成有后继的重复任务 | 状态/计数/后继任务遵循上游逻辑，无重复生成、误庆祝或恢复幽灵任务 |
| V03-06 庆祝判定 | 分别执行最后一项本地完成、筛选为空、折叠为空、启动加载、远端同步完成 | 仅符合真实清单转换且来源正确的事件庆祝一次；其他均不触发 |
| V03-07 添加/按压/滑动 | 逐项检查动画表；滑动未达/达阈值、手势中断、快速滚动 | 各动作反馈一致；一次手势一次业务操作；删除等动作能按现有语义恢复 |
| V03-08 无障碍与设置 | 大字号、朗读、减弱动画、关闭触感/玻璃、主题切换及重启 | 功能完整、标签清楚、设置持久化；不会以动画/颜色作为唯一状态提示 |
| V03-09 布局与性能 | 键盘、安全区、横竖屏、长清单滚动，按 v0.2.0 基线对照 | 无遮挡/手势冲突；测量达约定阈值，动画不造成连续操作锁定 |
| V03-10 同步与升级回归 | Dev 独立目录执行离线编辑、双端同步、冲突、导出恢复与覆盖升级 | 原本地/同步能力保持，数据与配置可恢复；UI 层没有自建同步真值 |

失败分支必须有可重复测试；仅“正常点了几次”不能证明动画与业务解耦。增加的自动化测试应重点覆盖事件来源、去重、失败/撤销和重复任务等逻辑，视觉手感与玻璃仍需实机。

## 失败分支与回退

| 失败 | 回退方式 | 放行条件 |
|---|---|---|
| 庆祝来源/完整清单状态不能可靠判断 | 关闭庆祝，保留任务级反馈，补适配层证据 | 判定用例全部通过后再开放 |
| 动画阻塞保存或引发并发错误 | 回退该动画接入到原任务接口直连；不修改核心来配合动画 | 数据与重复任务用例先通过 |
| 新导航使旧数据/功能不可达 | 恢复原入口或保留高级视图，修正实体映射 | 所有已有数据和本版日常路径可访问 |
| 液态/重动画卡顿 | 默认柔和/简洁或关闭，记录未达指标 | 默认配置达到性能与可访问性要求 |
| 数据格式出现意外改动 | 停止本版发布，核对真实 diff 与上游行为 | 保持兼容或单独评审迁移；不能仅回退 APK |
