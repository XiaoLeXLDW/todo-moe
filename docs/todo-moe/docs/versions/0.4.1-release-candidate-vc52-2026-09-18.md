# 0.4.1 Stable vc52：历史 checklist 兼容补丁

本补丁基于已发布的 0.4.0 Stable vc51，收录 PR #15 对历史或普通 `taskMode=task` checklist 的列表执行兼容。正式 APK 必须由本记录合并到 `main` 后的批准源码经受控工作流重新检查、构建和正式签名，不能把 Dev APK 政名发布。

## 收录范围

1. active 普通任务只要含有 checklist，折叠态即显示进度，点击任务主体可原地展开并逐项操作。
2. 小步骤点击直接持久化，列表内保留明确编辑入口；没有新增 schema，也没有改写既有 `taskMode`。
3. 普通任务完成最后一个 checklist 项时父任务保持未完成；真正的 `taskMode=list` 继续使用父任务原子完成、大型庆祝和精确撤销。
4. 已完成或归档的普通任务保持原查看行为，参考任务继续不可执行；多选、只读、滚动、侧滑和父任务完成入口不变。
5. 本轮只修 checklist 兼容，不修改同步、底栏、玻璃、AI、图标或发布系统。

## 正式发布门禁

- 语义版本：`0.4.1`；Stable versionCode：`52`；预期 tag：`moe-v0.4.1-vc52`。
- 本发布资料 PR 合并后，只接受可从 `origin/main` 到达的完整批准 SHA。
- 受控工作流必须从该 SHA 重新通过检查、无签名构建、正式密钥隔离签名、证书指纹和 APK 哈希回读。
- GitHub Release 必须包含签名 APK、`SHA256SUMS`、`release-manifest.json` 和 `RELEASE-NOTES.md`，公开后重新下载核对。

用户已明确授权本轮正式签名和公开发布。此记录不提前填写 Stable APK 大小、SHA-256、证书或 Release URL；这些字段只能从成功的正式工作流和已发布资产回读。
