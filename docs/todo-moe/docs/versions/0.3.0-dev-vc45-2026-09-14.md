## 根因与实现

vc44 的增强与夸张都调用同一个粒子生成器：任务均为 28 个、清单均为 54 个，大小、距离和弹道也相同。夸张档主要把任务碎片从 680ms 延到 900ms、清单庆祝从 1000ms 延到 1600ms；勾号虽有 1.9 倍峰值，但完整勾线在峰值之后才逐渐画完。因此实际观感接近“增强的慢放版”。

vc45 给粒子生成器加入显式 `lively` / `maximal` 配置，并把真实任务反馈宿主、设置预览和清单庆祝三条绘制路径全部接到同一强度配置：

| 项目 | 增强（保持） | 夸张（vc45） |
|---|---:|---:|
| 任务碎片 | 28 个；约 4.5–9.5dp；发射距离 72–134dp | 52 个；约 6.5–15.5dp；发射距离 118–260dp |
| 清单碎片 | 54 个；约 6–13dp；发射距离 135–250dp | 96 个；约 8.5–19.5dp；发射距离 210–440dp |
| 完成勾峰值 | 1.35 倍 | 2.65 倍；完整勾线画完时仍约 2.43 倍，之后保持明显放大 |
| 行位移 / 任务尾部 | 10dp / 680ms | 42dp / 1250ms |
| 清单徽章 / 总时长 | 80dp / 1000ms | 112dp / 2100ms |

粒子仍是不同起点、阻力、旋转、重力和寿命的碎片，不增加圆环或射线。真实任务行继续把碎片画在列表外的窗口反馈层，避免 Swipeable 或任务卡片裁切；清单动画继续使用原生窗口顶层 portal。飞出手机物理屏幕边缘的碎片会自然消失，这不等于全部粒子始终可见。
