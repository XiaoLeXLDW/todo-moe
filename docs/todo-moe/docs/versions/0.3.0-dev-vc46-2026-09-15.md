## 根因与修复

1. 项目文件夹、标签、状态、日期与分区保存现在等待真实 store 结果；显式失败或抛错保留选择器/输入草稿并告警，不再乐观关闭。标题使用独立可见草稿，修复提交时被 store 旧标题覆盖的二次回归。
2. 跨分区拖动先确认 `updateTask` 成功才执行顺序写入；失败时清掉未落地的视口锚点并显示错误，不用旧快照覆盖并发变更。
3. 手指向左滑只显示“更多＋删除”，按钮与任务行同高；手指向右滑不再暴露状态改动。进入多选、只读或禁滑状态会立即关闭已展开层，旧删除回调也会重新读取当前禁用状态。
4. 删除提示包含任务名，删除与完成共享一个“最新任务撤销”槽位；已领取的撤销 Promise 仍占用当前位，错误优先于普通队列，正在退场的旧提示不会复活。
5. 任务页顶部、项目操作层、文件夹/分区/附件弹层复用同一 `MoeGlassPanel`；项目路径上下间距拆开，图片预览的外层宽度约束保留，避免玻璃子节点收缩成窄列。
