# 0.4.2 Stable vc53：checklist 完成与删除让位补丁

本补丁基于已发布的 0.4.1 Stable vc52，只收录 PR #17、#18：修复旧 task-mode checklist 完成最后一步后父任务不完成，以及删除/恢复任务后相邻列表让位过慢。正式 APK 必须由本记录合并到 `main` 后的批准源码经受控工作流重新检查、构建和正式签名，不能复用或改名 Dev APK。

## 收录范围

1. 带 checklist、但仍保存为普通 `taskMode=task` 的历史任务，完成最后一个未完成项时，将完整 checklist 与父任务 `status: done` 一次写入。
2. 自动父任务完成继续触发现有大型 completion feedback；直接点击父任务完成按钮的既有路径不变。
3. Undo 使用写入前后快照：父任务恢复原状态，最后一次点击的小步骤恢复未完成，其他已完成项目不受影响。
4. 删除任务和撤销恢复前启动快速列表布局，相邻任务统一使用 180ms 让位；父任务退出、碎片粒子和清单庆祝时长不变。
5. reduced motion 继续关闭布局动画；本轮不修改数据 schema、同步协议、底栏、玻璃、AI、图标或发布系统。
