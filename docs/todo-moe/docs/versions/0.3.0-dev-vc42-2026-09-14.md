## 实现

移除普通完成、设置预览及整单庆祝的扩散圆圈和射线，不再让装饰在任务行消失后悬空。新增共用 `MoeCompletionCheck`，实际保留行与退出快照均使用同一笔画路径及回弹曲线；SVG 笔画由 JS 驱动，外层缩放由原生驱动，两者使用独立的 Animated View，避免驱动混用。

夸张档按压缩至 0.84 倍，勾号描出并弹至 1.6 倍再收回；任务快照、补位和退出统一为 420 ms，确认阶段先保留原位置，再一起淡出/补位。清单庆祝由大图案改为带 44dp 勾选标识、标题和清单名的紧凑确认卡，1 秒后收起。触感实现、原生玻璃、持久化与同步字段均无改动。
