## 根因与修复

1. 项目详情的通用保存入口在归档写入成功后仍用“可修改项目”过滤器回读。合法变成 `archived` 的项目因此被当成不存在，归档菜单不关闭，父级也收不到真实新状态。现在写入前仍要求项目可修改；写入后改为读取未删除的实际 store 对象，并明确验证归档状态，再把该对象发布给界面。
2. 文件夹/标签延迟写入成功后原来先读取项目并触发 `onBlocked`，之后才检查选择会话是否已经过期。用户从项目 A 切到 B 时，A 的旧回调仍可能污染 B。现在所有成功后的界面副作用都在会话检查之后执行；业务写入和失败报告不被取消。
3. 快速上手示例在人机可见的英文、简体中文和繁体中文中由 Sam 改为 Tibo，并重新生成静态字符串。内部翻译键 `starter.sampleReplySam` 按复查规格保留，不把内部兼容标识冒充用户文案。
4. 兼容识别继续接受历史 `Reply to Sam`、`回复 Sam` 和 `回覆 Sam`。升级或再次检查种子数据时，旧示例任务保持原文字且不会额外创建 Tibo 重复项；代码不会批量重写用户已有任务。

没有改动任务/项目 schema、同步协议、动画、触感或 vc47 已统一的单向滑动交互。
