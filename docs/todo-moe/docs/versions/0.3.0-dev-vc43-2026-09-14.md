## 本次变化与原因

普通完成包含 28 片三角碎块、斜切小片和细飞屑；每片有不同方向、大小、速度、旋转和延迟，先喷散再减速下落。夸张档任务行约 360ms 收起，碎片独立运行至最多 900ms。清单完成使用 54 片/1600ms 的更大爆散、中央大勾和清单文案。没有扩散圆圈或连接射线。

粒子轨迹由固定 seed 预计算，父组件只驱动一个 linear native progress，逐帧不运行 JS 物理计算。局部碎片仅在有效完成期间挂载；宿主依旧最多保留四组短期任务视觉身份。减少动画模式关闭粒子，撤销、滚动、页面切换与后台仍清理反馈。

遮挡处理有两处明确代码依据。设置庆祝原来位于 ScrollView 子树；在真实预览调用处加入裁切祖先断言，修复前 `expected true to be false`，修复后通过。真实保留完成行的 Swipeable 默认 overflow:hidden，会截断本地碎片。因此新增每个原生窗口的庆祝层：设置预览离开滚动子树，项目 Modal 使用最近窗口的 host；保留行的快照降为 particlesOnly，由原任务行画勾号/文字、外部反馈层画飞屑。

原生窗口庆祝层 pointerEvents 为 box-none，实际舞台为 none，不阻止操作。切页/隐藏窗口/后台清理也由 host 保底，避免冻结路由残留。触感、原生玻璃、数据库和同步 schema 均无变化。
