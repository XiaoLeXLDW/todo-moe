## 目标与范围

用 Android 真机证明：SukiSU/Miuix 风格的底栏能否在 Mindwtr 所选 React Native/Expo 基线上正确处理背后的动态列表，并保留完整的触控、键盘与系统导航行为。本版输出技术路线结论，不凭静态截图宣布液态玻璃成功。

| 纳入范围 | 本版不做 |
|---|---|
| 优先核对用户曾在其他 App 用成功的底栏版本；补齐来源、依赖及许可证 | 不假定本地已有那个项目，不默认 SukiSU 最新 main 等同已成功版本 |
| 可滚动 RN 测试列表 + 独立原生底栏小样 | 不为底栏把整个 App 重写成 Kotlin，不同步升级 Expo/RN 与重构导航 |
| 动态背景采样、点击/拖动、返回、键盘、安全区、旋转、性能 | 不用 JS 定时截图伪造实时背景，不把半透明填色标成动态模糊 |
| 关闭/柔和/液态的能力探测与可靠降级原型 | 不承诺所有 Android 版本或机型有相同液态效果 |
| RN 侧替代方案对照与独立可移除接入 | 不扩展为全屏玻璃卡片、复杂设置页或正式主题重做 |

“参考 SukiSU 的底栏与主题”来自用户明确要求；具体桥接方式、设置档位和降级顺序属于本次工程建议。用户历史使用成功只证明那个 App 的经历，不证明 RN 背景采样已经解决。

## 功能与接口要求

底栏接收导航条目、当前选择、颜色与效果档位；向现有导航层报告选择事件。它不保存任务、不维护第二套路由状态，也不获得同步凭据。点击一次只发生一次路由变化；拖动选中如需实现，必须不抢占列表滑动和系统返回。

背景真实性使用“静止底栏 + 持续改变其后方内容”的录屏验证。应能从色块位置看出采样来自正确区域，拖动和滚动时实时更新；弹出键盘、切换页面或返回前台后不残留上一帧内容。

效果档位建议为“关闭 / 柔和 / 液态”。若液态不可用，明确降级到经验证的模糊或实底，底栏按钮、选中态和文字对比度保持完整。实际界面名称和默认档位在 v0.3.0 定稿。

## 验收用例与通过条件

以下 `V02-*` 是 [统一 QA 矩阵](../05-测试与发布维护.md#2-测试矩阵) 的本版细项：V02-01/06→QA-04；V02-02/03/04→QA-05；V02-05→QA-14；V02-07→QA-09；V02-08→QA-03/10。

| 用例 | 操作 | 通过条件 |
|---|---|---|
| V02-01 动态真实性 | 高对比 RN 内容连续滚动穿过底栏后方；切换不同颜色页面 | 录屏可辨认模糊/折射随真实内容实时变化，无冻结、错位或仅透明叠色；说明采样机制 |
| V02-02 导航与手势 | 连续点击、快速切页、底栏拖动（若实现）、列表上下/横向手势、系统返回 | 路由和选中态一致；无双触发、误滑、触控死区或系统手势被吞 |
| V02-03 键盘与布局 | 快速添加输入，键盘开合；手势/三键导航（可用时）、横竖屏、安全区 | 输入框、提交键和最后一条任务可访问；底栏不覆盖系统导航和必需内容 |
| V02-04 生命周期 | 前后台切换、主题变化、页面离开返回、组件反复挂载卸载 | 无旧画面残留、事件重复订阅、原生崩溃或持续资源增长 |
| V02-05 性能对照 | 同设备同数据集，关闭/柔和/液态分别执行相同滚动与切页轨迹，各重复 3 次 | 记录刷新率、帧时间/卡顿、CPU、内存和可观察温度；通过阈值在跑测前登记，不根据结果倒改标准 |
| V02-06 降级与重启 | 手动关闭效果、模拟能力不支持或初始化失败，重启后进入 | 始终可导航与添加任务；设置可保存，不循环崩溃；不支持状态与降级结果可查 |
| V02-07 可读与无障碍 | 明暗主题、高对比背景、大字号、辅助朗读与减少动画设置 | 标签可读、焦点/选中信息明确、控件可触达；不依赖模糊或动画识别状态 |
| V02-08 数据回归 | 同基线完成创建、编辑、完成、撤销与测试同步 | 玻璃模块未改变任务结果或同步行为；没有数据层改动则以已有基线用例复验接入点 |

性能阈值初始建议：同设备与同数据集的 P95 帧时间不超过关闭效果基线的 1.2 倍，卡顿比例增加不超过 2 个百分点；若基础页面本身明显卡顿，应先定位基线。该数值是本次建议，不是历史事实或已测结果。能力不足时默认使用更轻效果，不能以“看起来差不多”替代原始数据。测量工具不支持某指标时标明缺项并采用有说明的替代指标。

## 失败分支与回退

| 结果 | 处理 | 是否可进入 v0.3.0 |
|---|---|---|
| 仅底栏出现，RN 动态采样未通 | 固定失败复现，核对原生窗口/渲染层关系；不要继续堆光泽装饰掩盖问题 | 不能宣称原生路线验证通过 |
| 原生路线需大范围侵入 RN/核心 | 记录代价，采用 RN 侧兼容实现并保留视觉/交互方向 | 替代路线完成同等交互和降级验收后可进入 |
| 液态效果性能不合格 | 以柔和或关闭档位默认，保留实验开关仅限 Dev 或移除失败实现 | 文档明确效果缩减，日常页面达到阈值后可进入 |
| 键盘/系统手势不可稳定修复 | 回退独立模块接入到 v0.1.0 普通底栏 | 该问题清零前不放行玻璃接入 |
| 来源许可或依赖归属不清 | 不复制相关代码；补齐来源或用允许且可追溯的替代实现 | 有完整来源清单才能作为可维护交付 |
