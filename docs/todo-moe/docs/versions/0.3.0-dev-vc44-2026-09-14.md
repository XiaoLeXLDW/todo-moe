## 复现与根因

vc43 在同一预览控件上完成“勾选 → 取消 → 撤销 / 重试”后，UIAutomator 回读为 `checked=false`，任务文字也没有删除线，但设备截图仍有绿色填充勾号。证据为 `evidence/development/device-20260914-vc44-settings/vc43-reset-stale.png`。这把问题限定为动画绘制残留，而不是预览业务状态没有复位。

勾号的 SVG 揭示值与缩放分别由 JS/native 动画驱动。旧实现即使 `checked` 已变为 false，仍继续挂载勾号组件并依赖反向动画把它藏起来；动画被快速切换或停止时，旧图形可能保留。现在由权威 `checked` 状态直接控制勾号组件是否存在：取消、Undo 或复位立即卸载图形并将动画值归零，不再等待一段可被中断的隐藏动画。完成时的爆散和触感调用没有改动。

共享 `AppPressable` 原来把函数形式的 Pressable 样式直接交给 Animated 包装层。原生动画属性归并不能可靠保留这类函数返回的尺寸、背景和边框，真机上因此出现选择项只剩文字、按钮互不一致。现在先用当前 pressed 状态解析完整样式，再把静态布局、既有 transform 和按压缩放一起交给 Animated 控件。

外观和动画与触感页面不再使用单独的一套大圆角布局。两页复用原设置模块的滚动留白、分组标题、12px `settingCard`、`settingRowColumn`、`pickerOption` 和标准开关行。明暗、配色、玻璃、动画、触感及试听均使用同一描边选择控件；演示区放在页面末尾并保持 `overflow: visible`，不会重新引入庆祝裁切。
