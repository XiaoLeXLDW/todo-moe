## 收录范围

1. 项目元数据、分组和跨分组移动等待真实写入结果，失败时保留或恢复可操作界面。
2. 任务行与清单卡片统一为单方向左滑动作轨；右滑无动作，多选和只读状态使旧回调失效。
3. 完成与删除共用最新撤销槽，错误提示优先，异步撤销结束后才关闭对应提示。
4. 项目文件夹和标签选择器加入项目、可见性与会话 revision 保护；真实归档发布 store 新状态，重新激活闭环恢复。
5. 三种主语言快速上手示例改为 Tibo；历史 Sam 仅作防重复识别，不改写用户任务。

没有改变任务/项目 schema、同步协议、Stable 包名或正式签名身份。任务同步仍按本轮 local-only 边界保持未启用。

## 正式发布门禁

- 语义版本：`0.3.1`；Stable versionCode：`50`；预期 tag：`moe-v0.3.1-vc50`。
- PR #12 合并后，只接受可从 `origin/main` 到达的完整批准 SHA。
- 受控工作流必须重新通过检查、无签名构建、正式密钥隔离签名、证书指纹和 APK 哈希回读。
- GitHub Release 必须包含签名 APK、`SHA256SUMS`、`release-manifest.json` 和 `RELEASE-NOTES.md`，并在公开后重新下载核对。

此记录不提前填写正式 APK 的大小、SHA-256、证书或 Release URL；这些字段只能从成功的正式工作流和已发布资产回读。
