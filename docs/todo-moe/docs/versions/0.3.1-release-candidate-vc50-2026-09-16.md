# 0.3.1 Stable vc50：正式发布记录

本版把已发布的 `0.3.0 / vc45` 之后四轮清单修复收为补丁版 `0.3.1 / vc50`。实现和前置真机基线来自 [Dev vc49](0.3.0-dev-vc49-2026-09-16.md)；正式 APK 已由合并到 `main` 的批准源码经受控工作流重新检查、构建和正式签名，没有把 Dev APK 政名发布。

## 收录范围

1. 项目元数据、分组和跨分组移动等待真实写入结果，失败时保留或恢复可操作界面。
2. 任务行与清单卡片统一为单方向左滑动作轨；右滑无动作，多选和只读状态使旧回调失效。
3. 完成与删除共用最新撤销槽，错误提示优先，异步撤销结束后才关闭对应提示。
4. 项目文件夹和标签选择器加入项目、可见性与会话 revision 保护；真实归档发布 store 新状态，重新激活闭环恢复。
5. 三种主语言快速上手示例改为 Tibo；历史 Sam 仅作防重复识别，不改写用户任务。

没有改变任务/项目 schema、同步协议、Stable 包名或正式签名身份。任务同步仍按本轮 local-only 边界保持未启用。
