## 根因与修复

1. `ProjectRow` 原来用 `renderLeftActions` 提供复制、用 `renderRightActions` 提供删除，导致两个低频操作分布在相反手势；现在只保留 `renderRightActions`，手指向左一次拉出复制和删除。
2. 项目卡片原用 96dp、8dp 圆角的独立按钮，也没有任务行动画；现在项目卡片与任务行共用 `MoeSwipeActionsTrack`，统一 78dp 按钮、14dp 圆角、8dp 间隔，以及透明度、横移和缩放插值。
3. 两处共用摩擦 `1.25`、打开阈值 `72`、边缘拖动阈值 `28` 和关闭右侧回弹；轨道宽度为 `78 + 8 + 78 + 8 = 172dp`，与动画位移输入一致。
4. 项目卡片底部间距由 8 调整为 6，与共享轨道及任务行一致；测试锁定三者相等，避免再出现展开后底边相差 2dp。
