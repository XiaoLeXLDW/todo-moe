# Changelog

## Todo Moe releases

- [0.4.2 / Stable vc53](https://github.com/XiaoLeXLDW/todo-moe/releases/tag/moe-v0.4.2-vc53) — historical checklist tasks complete their parent on the final step, checklist undo preserves newer edits, and delete/restore list reflow is faster. See the [release record](docs/todo-moe/docs/versions/0.4.2-release-candidate-vc53-2026-09-19.md) for exact evidence and limitations.
- [0.4.1 / Stable vc52](https://github.com/XiaoLeXLDW/todo-moe/releases/tag/moe-v0.4.1-vc52) — checklist tasks became directly executable from the main task lists, including compatibility for historical task modes. See the [release record](docs/todo-moe/docs/versions/0.4.1-release-candidate-vc52-2026-09-18.md).
- [0.3.1 / Stable vc50](https://github.com/XiaoLeXLDW/todo-moe/releases/tag/moe-v0.3.1-vc50) — settings, motion, task-list gestures, archive handling, and product identity were consolidated. See the [release record](docs/todo-moe/docs/versions/0.3.1-release-candidate-vc50-2026-09-16.md).
- [Complete Todo Moe version index](docs/todo-moe/docs/versions/README.md)
